常见问题

FFmpeg 怎么安装？

Windows 10/11 打开 PowerShell（管理员），运行 winget install ffmpeg。安装后关闭所有 CMD 窗口，重新打开，输入 ffmpeg -version 验证。

如果 winget 下载失败，可以用中科大镜像源：

winget source remove winget
winget source add winget https://mirrors.ustc.edu.cn/winget-source --trust-level trusted
winget install ffmpeg

.bat 文件应该放哪里？

放到你要处理的视频所在的文件夹，和视频文件放在一起。双击运行后，脚本会处理当前文件夹里的所有匹配文件，输出到子文件夹。

为什么不能直接复制命令？

命令里包含 %%F、%OUT% 等批处理专用变量，直接粘贴到 CMD 会报错。这些变量只有在 .bat 文件里才生效。

双击 .bat 闪退怎么办？

最常见原因是没装 FFmpeg。右键 .bat → 在终端中打开，看完整输出。

Chrome 提示「可能有害」怎么办？

点「保留」即可下载。Chrome 对所有 .bat 文件都会提示，不是脚本有问题。

输出文件在哪？

在 .bat 同目录下的子文件夹里：压缩 → finished/，合并 → merged/，转格式 → converted/，裁剪 → cut/。

想重新处理怎么办？

关闭「跳过已存在」，或改文件名后缀，生成新文件名，旧结果保留。

文件会上传吗？

不会。整个网站是纯前端，没有服务器。浏览器只读取文件名、大小等元数据，不读取内容。所有处理在本地用 FFmpeg 完成。

支持 macOS / Linux 吗？

目前只支持 Windows（生成 .bat 脚本）。macOS / Linux 的 .sh 脚本后续考虑。

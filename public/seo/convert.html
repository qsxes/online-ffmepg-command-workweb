视频批量转格式

MP4 / MKV / MOV / WebM / AVI 互转，也可以只提取音频或只提取视频。

支持的格式

  • 输入：mp4 / mkv / mov / avi / webm / ts
  • 输出：mp4 / mkv / mov / webm / avi / mp3 / wav

提取模式

  • 正常转换：视频和音频都保留
  • 只提取音频：丢弃视频轨，输出 mp3 / wav
  • 只提取视频：丢弃音频轨

使用步骤

  1. 安装 FFmpeg：winget install ffmpeg
  2. 打开工具页，选输入/输出格式和编码器，下载 .bat
  3. 把 .bat 放到视频文件夹，双击运行

特点

  • 支持 copy 模式（不重新编码，秒级完成），也支持重新编码（兼容性最好）
  • 文件不上传，本地处理
  • 免费，开源

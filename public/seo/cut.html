视频 / 音频裁剪

在浏览器里本地预览，选起止时间，支持多片段管理，生成可双击运行的 .bat 脚本。

支持的格式

  • 视频：mp4 / mkv / mov / avi / webm / ts
  • 音频：mp3 / wav / m4a / flac / aac / ogg

裁剪模式

  • 快速裁剪：不重新编码，秒级完成。起始点可能有 1-2 秒偏移
  • 精确裁剪：重新编码，帧级精确，速度较慢

使用步骤

  1. 安装 FFmpeg：winget install ffmpeg
  2. 打开工具页，选文件，本地预览，设置入点和出点
  3. 添加到片段列表，可添加多段，下载 .bat
  4. 把 .bat 放到文件所在文件夹，双击运行

特点

  • 浏览器本地预览，文件不上传
  • 支持多片段，一次生成多个裁剪结果
  • 免费，开源

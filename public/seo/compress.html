批量压缩视频

在线生成 FFmpeg 批量压缩脚本，把当前文件夹里的视频批量压小。

支持

  • 编码器：H.264（兼容性好）/ H.265（体积更小）
  • 画质：CRF 18-28 可调
  • 编码速度：ultrafast / fast / medium / slow
  • 分辨率：保持原始 / 1080p / 720p / 480p
  • 音频码率：96k / 128k / 192k

使用步骤

  1. 安装 FFmpeg：winget install ffmpeg
  2. 打开工具页，选好参数，下载 .bat 脚本
  3. 把 .bat 放到视频文件夹，双击运行

特点

  • 文件不上传，浏览器只生成脚本，处理在本地用 FFmpeg 完成
  • 不需要注册、不需要联网（生成脚本后）
  • 生成的 .bat 可以保存、复用、发给别人
  • 免费，开源

按文件名合并视频 / 音频

按文件名的自然顺序（1 → 2 → 10）合并当前文件夹里的视频或音频文件。

支持的格式

  • 输入：mp4 / mp3 / ts / mkv
  • 输出：合并为单个文件，扩展名与原格式一致

合并模式

  • 快速合并：不重新编码，秒级完成。要求所有文件的编码、分辨率、帧率一致
  • 重新编码：兼容性最好，任何视频都能合，速度较慢

使用步骤

  1. 安装 FFmpeg：winget install ffmpeg
  2. 打开工具页，选输入格式和合并模式，下载 .bat
  3. 把 .bat 放到视频文件夹，双击运行

特点

  • 文件不上传，本地处理
  • 自然排序，正确处理数字文件名
  • 合并失败时脚本会提示改用重新编码
  • 免费，开源

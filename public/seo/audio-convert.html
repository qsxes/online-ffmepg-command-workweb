音频批量转格式

MP3 / WAV / M4A / FLAC / AAC / OGG / AMR 等 10+ 格式互转。

支持的格式

  • 输入：mp3 / wav / m4a / flac / aac / ogg / opus / amr / ape / 3gp / wma
  • 输出：mp3 / wav / m4a / aac / flac / ogg

适用场景

  • m4a 转 mp3 发给别人
  • flac 转 mp3 放车里听
  • amr（安卓通话录音）转 mp3 存档
  • 任意格式转 16kHz 单声道 WAV，喂给语音识别工具

语音识别预设（ASR）

开启后自动输出 16kHz / 单声道 / WAV，适合喂给 Whisper、通义听悟等工具。

使用步骤

  1. 安装 FFmpeg：winget install ffmpeg
  2. 打开工具页，选输入/输出格式，下载 .bat
  3. 把 .bat 放到音频文件夹，双击运行

特点

  • 文件不上传，本地处理
  • 支持无损格式（WAV / FLAC）和有损格式互转
  • 免费，开源
